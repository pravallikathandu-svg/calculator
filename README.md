# Modern Dark Calculator 🧮

A sleek, responsive, iOS-inspired minimalist calculator built with pure HTML, CSS (CSS Grid), and Vanilla JavaScript.

## ✨ Features

- **iOS-Inspired Dark Mode:** Polished obsidian theme with clean contrasting typography and vibrant orange action keys.
- **CSS Grid Layout:** Fluid 4-column grid layout with custom spans (like the iOS wide `0` button).
- **Core Arithmetic:** Addition, subtraction, multiplication, and division.
- **Edge-Case Handling:** Guard rails for division by zero (`Error`), floating-point precision rounding (e.g., `0.1 + 0.2 = 0.3`), and preventing duplicate decimals.
- **Additional Operations:** Instant percentage calculation (`%`), backspace deletion (`DEL`), and all-clear (`AC`).
- **Full Keyboard Support:** Use physical number keys, `+`, `-`, `*`, `/`, `Enter` (`=`), `Backspace`, and `Escape` (`AC`).

## 🚀 Getting Started

Simply open `index.html` in any modern web browser—no servers, dependencies, or installations required.
